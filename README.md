# Clairé Women's Atelier

A premium women-only salon website sample created for demonstration.

## Preview locally

Open `index.html` in a browser, or run a simple local web server in this folder.

## Included

- Video-led hero aesthetic
- Salon services and sample pricing
- Appointment request form
- Demo login and Clairé Circle loyalty petals
- Responsive mobile layout

The visual media and fonts load from online providers, so use an internet connection for the complete experience.
